# Facilitator usage guide

How to run a live session with the GDR Teambuilding Tool.

1. **On startup**, pick a recent / pre-installed scenario, or create a new one.
2. To **prepare** a scenario, open it in **Edit scenario**: load the map, create characters (face crop, name, color), add objects, position everything, and save the initial positions. Everything is autosaved (a save indicator sits in the toolbar).
3. To **play**, open it in **Run session**: drag the Stage window onto the projector and click *Fullscreen projection*. From there, move characters, assign objects, launch conflicts on the wheel, run the timer and the leaderboard. **Nothing done live is saved**: reopening the scenario always resets to the setup state.

See the [main README](../README.md) for a feature overview, and [`DEVELOPMENT.md`](DEVELOPMENT.md) for how to build and run the tool from source.
